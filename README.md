# Supermarket Sales Analysis

This project contains a complete analysis of supermarket sales data using **Python (Jupyter Notebook)** for data cleaning and **Power BI** for visualization.

## Project Overview
The goal of this project is to analyze supermarket sales data to understand customer behavior, product performance, and sales trends across different cities. The cleaned dataset and visualizations provide insights for data-driven decision making.

## Files in the Repository
- `supermarket_sales_analysis.ipynb` – Jupyter Notebook containing data cleaning, preprocessing, and exploratory analysis steps.
- `cleaned_data.csv` – Cleaned dataset exported from the notebook.
- `Sales_Dashboard.pbix` – Power BI file with interactive visualizations.
  
## Tools and Technologies
- **Python 3.13**  
- **Jupyter Notebook**  
- **Pandas**, **NumPy** for data manipulation  
- **Power BI** for interactive dashboards and visualizations  

## Key Analysis and Insights
- Sales by **city** and **branch**  
- Sales by **product category** and **customer type**  
- Identification of high-performing products and top customers  
- Insights on sales trends and patterns to inform business decisions  

## How to Use
1. Open `supermarket_sales_analysis.ipynb` in Jupyter Notebook to see the data cleaning and analysis workflow.  
2. Open `Sales_Dashboard.pbix` in Power BI Desktop to view and interact with the visualizations.  
3. `cleaned_data.csv` can be used for further analysis or as input to other data tools.
